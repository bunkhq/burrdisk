# Security policy

## Supported versions

Only the latest release gets fixes. Burrdisk updates itself, so most people are already on it.

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately through [GitHub's private vulnerability reporting](https://github.com/bunkhq/burrdisk/security/advisories/new).

Include the version, your OS, and steps to reproduce if you have them. You should get a reply within a week.

Problems that matter most here:

- the updater, which downloads and installs new versions;
- anything that could delete files without going through the Trash or the Collector's countdown;
- scans run as administrator (Rescan as Administrator).
